An agent pays per call in USDT and spends no gas at all.

Standard x402 needs EIP-3009, which BOT Chain's USDT doesn't have — so this settles with x402's batch-settlement scheme: prepaid vault, off-chain EIP-712 vouchers signed by the payer, and a permissionless settle() that batches them. The payer's key signs; the server pays the gas.

Wire it into an agent

Module 01 is an MCP server, so any MCP-capable agent gets chain read access with no integration code:

claude mcp add botchain -- node /root/botchain-mcp/src/index.js
hermes mcp add botchain --command node --args /root/botchain-mcp/src/index.js

Module 02 needs no SDK. Hit a paid route, meet the 402, sign the voucher, re-send it:

GET /v1/votes/508?hours=6          ->  402 { accepts:[{ maxAmountRequired:"10000", extra:{ invoiceId, expiry } }] }
sign EIP-712 Voucher                ->  { agent, payee, amount, invoiceId, expiry, chainId, vault }
GET /v1/votes/508  X-PAYMENT: <base64>  ->  200 { data, payment:{ transaction, explorer } }
