03 / HTTP 402

The challenge is the invoice.

The server tells the agent exactly what to sign: scheme, network, asset, payee, amount, expiry and invoice ID.

{
  "x402Version": 2,
  "scheme": "batch-settlement",
  "network": "eip155:968",
  "asset": "0x4D3f…c5c1",
  "amountFormatted": "0.001 USDT",
  "extra": {
    "vault": "0xD6ee…2586",
    "invoiceId": "0x…",
    "expiry": 1759754000
  }
}
